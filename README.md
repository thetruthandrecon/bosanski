# Bosanski: A Workbook for Learners – Phone Companion

This is the free interactive companion to the paperback **Bosanski: A Workbook for Learners – From A1 to A2 in Ten Units**.

**Open it here:** https://thetruthandrecon.github.io/bosanski/

## What you get
- All ten units, the placement test, the final A2 test, the reference appendix and the glossary
- A text box under every exercise – type your answer, tap **Check**, see the model answer
- Buttons for č ć š ž đ so you don't need a Bosnian keyboard
- Progress saved on your phone; nothing is sent anywhere
- Works offline once opened – choose **Add to Home Screen** in your browser to use it like an app

## How to use it
1. Do the **Placement Test** first.
2. One unit a week: read the explanation, do the exercises, check, then re-do the ones you missed two days later.
3. Tick the **Can you…?** list at the end of each unit before moving on.
